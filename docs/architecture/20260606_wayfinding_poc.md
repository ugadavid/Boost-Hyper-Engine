# Way-finding POC

## 1. Context

This POC belongs to the `experiment/bhe-be` branch.

The analyzed brick is:

```txt
Wayfinding 1 revamp - V2.pdf
```

It was selected after the corpus cartography because it appeared to combine several unusually concrete pedagogical signals:

```txt
situated communication
+
map-based action
+
real-world success condition
```

The goal of this document is not to confirm a theory and not to force `Moment`, `PedagogicalTransition`, or any new BHE concept into the reading.

The goal is only:

```txt
observe
pressure-test
surface signals
```

## 2. What This Brick Seems To Do

At the learner-facing level, the brick teaches how to ask for and give directions to a nearby location.

The sequence is practical:

```txt
complete a directions dialogue
-> follow a conditional learning path
-> review key language
-> watch/listen with a map
-> practise polite question forms
-> complete a final test
-> prepare directions on a real map
-> share and test with classmates
```

The brick starts with a gap-fill / drag-and-drop dialogue. It then branches depending on the learner's score on `I start`: learners below the threshold appear to receive a more supported video/key-language path, while stronger learners may go to a BBC listening/reading path.

The later stages move toward map use and oral exchange. The `I share` section is especially important: the learner prepares instructions from Trinity College to a chosen location on a Dublin map, then shares them with a classmate to check whether the instructions are clear and the classmate reaches the expected location.

This is not just grammar practice.

The language is embedded in a practical task:

```txt
Can another person use what I said?
```

## 3. What Is Actually Being Taught?

Several layers are present.

### Directions Vocabulary

The brick clearly teaches vocabulary and phrases:

- nearest;
- on;
- down;
- take;
- first;
- then;
- past;
- cross;
- left;
- next to;
- how do I get to...;
- can you tell me the way to...;
- do you know the way to...

This layer is visible in the initial drag-and-drop, vocabulary review, multiple-choice items, and final test.

### Communicative Ability

The brick also teaches a communicative act:

```txt
ask for directions
give directions
respond politely
```

The voicework section makes this explicit. The learner is not only asked to choose correct words. They practise polite openings, pausing, emphasis, and clear pronunciation.

### Navigation Strategy

There is a spatial/navigation layer.

The learner must connect language to map movement:

- identify landmarks;
- follow routes;
- understand sequence;
- interpret relative location;
- produce instructions that can guide another person.

This is different from merely knowing the meaning of `left`, `right`, or `past`.

### Situated Language Use

The strongest signal is situated language use.

Language is taught as something that works inside a situation:

```txt
person A needs to reach a place
person B gives directions
the map constrains the possible answer
success can be checked by action
```

This gives the brick a functional success condition that many grammar bricks do not have.

### Something Else: Action Reliability

The `I share` and `For teachers` sections suggest another layer:

```txt
Are my instructions reliable enough for someone else to act on them?
```

This is not only correctness.

An instruction may be grammatically acceptable but still unclear, incomplete, badly ordered, or hard to follow.

## 4. Learner-State Changes

Possible learner-state changes are visible, but should remain cautious.

### Knows Words -> Can Use Directions

This is a plausible transition.

The learner may begin with isolated direction words and formulae, then gradually connect them to a route. This movement appears in:

- the initial dialogue;
- map-supported video work;
- listening for directions;
- final map identification;
- the Dublin map sharing task.

This transition seems stronger than a simple vocabulary acquisition path.

### Passive Vocabulary -> Situated Communication

This is also plausible.

The learner is not only asked to recognize direction words. They are asked to produce instructions that someone else can test.

This transition is especially visible in:

```txt
prepare directions
-> share with a classmate
-> check whether they end up in the expected location
```

### Grammar Learner -> Functional Communicator

This signal is present, but should not be overstated.

The brick includes form-focused and quiz-like activities. However, the final classroom-facing uses pull the learner toward functional communication. The learner is not simply practicing prepositions; they are using prepositions to make another person's action possible.

### Lost -> Able To Orient

This is an attractive reading, but it may be more thematic than directly observable.

The learner is not literally lost. The brick simulates a navigation need. Still, the sequence creates a controlled version of orientation:

```txt
uncertain route
-> interpretable route
```

This is worth noting, but not making too grand.

## 5. Emerging Responsibilities

This brick may reveal a responsibility that was less visible in previous POCs:

```txt
action-oriented validation
```

The question is not only:

```txt
Is the answer linguistically correct?
```

It becomes:

```txt
Can the language support a successful action?
```

This does not mean BHE needs a new concept now. It only suggests a signal worth preserving.

Other possible responsibilities appear:

### Situated Communication

Language is treated as situated action, not only formal correctness.

The map, route, destination, listener, and social politeness all matter.

### Contextual Language Activation

The learner has to activate known or newly learned language inside a concrete context. The context shapes what counts as useful language.

### Communicative Realism

The final success condition is socially and practically realistic:

```txt
my classmate can follow my directions
```

That is a different kind of validation from a timed grammar quiz.

### Adaptive Scaffolding

The conditional path after `I start` is interesting, but still rough.

It may express:

```txt
learner positioning
-> adjusted preparation
```

or:

```txt
if weak initial performance
-> more supported key-language path
```

This is pedagogically interesting, but not yet enough to stabilize an adaptive model. The PDF itself still contains open implementation questions about whether learners on one path may access the other path too.

### Teacher Orchestration

The teacher section strengthens the action signal.

Students take turns giving directions on a printed map, exchange written directions without naming the destination, and test where classmates end up. The teacher-facing work extends the learner-facing brick into real classroom verification.

## 6. Comparison With Previous POCs

### Thinking In English

`Thinking in English` is about internal posture and oral activation:

```txt
self-awareness
-> speaking readiness
```

`Way-finding` is more external and action-facing:

```txt
language knowledge
-> usable communicative action
```

Both involve speaking, but the success condition differs. In `Thinking in English`, the learner crosses a threshold toward speech. In `Way-finding`, the speech must guide someone.

### Memorising Vocabulary

`Memorising vocabulary` teaches learning strategy awareness:

```txt
implicit learning habits
-> intentional memorization strategy
```

`Way-finding` teaches functional language use:

```txt
language items
-> situated route guidance
```

Both move beyond content delivery. One changes how the learner learns; the other tests whether language can function in a practical situation.

### Countable & Uncountable

`Countable & Uncountable` has strong conceptual scaffolding:

```txt
examples
-> reasoning question
-> grammatical distinction
```

`Way-finding` is less about conceptual discovery and more about operational success. The learner may need grammar and vocabulary, but the central question becomes whether they can use these resources in sequence to solve a communicative navigation task.

### Question Forms

`Question Forms` served as a negative case because it looked closer to:

```txt
rule
-> exercise
-> more rule
```

`Way-finding` contains quizzes and controlled practice too, but they appear to feed a more situated endpoint. The practice does not only accumulate correctness; it prepares a map-based communicative action.

This contrast is useful.

The presence of exercises alone does not make a brick conventional. The question is whether those exercises are coordinated toward a meaningful use condition.

## 7. Temporary Conclusion

This POC does seem to reveal a signal that is different from the previous ones.

It reinforces known distinctions:

```txt
interaction shape
!=
pedagogical function
```

and:

```txt
quiz/practice
!=
only assessment
```

But its sharper contribution is:

```txt
correct language
!=
successful communicative action
```

The brique seems to validate both language correctness and practical communicative success, but not at the same level.

The controlled exercises validate local language resources:

- words;
- phrases;
- prepositions;
- polite question forms;
- route expressions.

The map and sharing tasks validate whether those resources can be used for action:

```txt
Can another learner follow the route and end up in the expected place?
```

The main intuition to preserve is therefore:

```txt
some pedagogical bricks validate action reliability,
not only answer correctness
```

This should remain an analytical signal for now. It is not yet a BHE object, runtime layer, or architecture decision.
