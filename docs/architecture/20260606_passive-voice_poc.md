# Passive Voice POC

## 1. Context

This POC belongs to the `experiment/bhe-be` branch.

The analyzed brick is:

```txt
2. Passive voice - Final - Carole.pdf
```

The brick was selected because the corpus cartography identified it as high-potential. Unlike some previous POCs, the central pressure-test here is not only:

```txt
What is this brick trying to change in the learner?
```

but also:

```txt
Does this brick resist simplification?
```

In other words:

```txt
one dominant pedagogical move
or
multiple pedagogical moves coexisting?
```

This document does not try to force `Moment`, `PedagogicalTransition`, or any new concept. It treats the brick as a real pedagogical object with possible internal tension.

## 2. What This Brick Seems To Do

At the learner-facing level, the brick teaches the passive voice.

The sequence is mostly recognizable:

```txt
song exposure
-> notice passive forms
-> grammar lesson / summary
-> controlled practice
-> voicework
-> timed test
-> sharing prompt
-> teacher extensions
```

The core introduction is explicit:

- identify active voice and passive voice;
- rephrase sentences to focus on what or who is affected by an action.

The brick begins with a song and asks learners to notice passive forms. It then provides a lesson and bilingual summary explaining the passive structure:

```txt
subject + be + past participle (+ by + object)
```

The practice section asks learners to:

- identify passive sentences;
- decide whether the focus is on the agent or the object;
- transform active sentences into passive forms.

So the dominant visible layer is grammar recognition and transformation.

But the teacher-facing section expands the possible pedagogical function. It proposes:

- reading a newspaper article and discussing why passive voice was used;
- considering passive voice as a tool that can distort historical narratives;
- writing explanations of how devices work;
- playing a guessing game based on passive descriptions of objects.

That extension makes the brick harder to reduce to grammar practice only.

## 3. What Is Actually Being Taught?

Several layers appear.

### Passive Voice Grammar

This is the central and most explicit layer.

The learner is taught:

- active vs passive;
- `be` plus past participle;
- tense transfer from active to passive;
- optional use of the agent with `by`;
- regular and irregular past participles.

This layer is strongly represented in the lesson, examples, practice exercises, and final quiz.

### Focus Awareness

The brick is not only about form.

The explanation repeatedly says that passive voice changes focus:

```txt
agent
-> object / affected thing
```

This is a semantic/discourse layer.

The learner is not only asked:

```txt
Is this passive?
```

but also:

```txt
Who or what receives attention?
```

### Discourse Awareness / Critical Reading

The `For teachers` section introduces a stronger move.

The proposed article about passive voice as a possible manipulation tool turns grammar into discourse awareness:

```txt
grammar
-> framing
-> critical reading
```

This is not central in the learner-facing test, but it is pedagogically significant. It suggests that passive voice can shape how responsibility, agency, and historical events are perceived.

This is the clearest place where the brick resists simplification.

### Communicative Explanation

The writing extension about devices introduces another use:

```txt
grammar
-> explaining systems
```

Examples:

- smartphone;
- washing machine;
- coffee machine;
- 3D printer;
- laptop.

Here passive voice becomes useful because the object or process matters more than the agent. The learner uses grammar to explain how something works.

This is not exactly critical literacy. It is functional/technical explanation.

### Collaborative Meaning Making

The guessing game adds a social layer.

Students read passive descriptions of objects without naming them. Others guess the object.

This turns passive voice into:

```txt
language
-> communicative play
-> collaborative interpretation
```

The grammar still matters, but the activity validates whether the description is understandable enough for others to infer the intended object.

## 4. Learner-State Changes

Several possible learner-state changes coexist. They are not all equally strong.

### Isolated Form -> Focused Meaning

This is the strongest learner-facing transition.

The learner begins with passive forms in lyrics, then learns that passive voice changes focus:

```txt
who did it?
-> what was affected?
```

This transition is explicit and central.

### Correct Structure -> Purposeful Language Use

This transition is present, especially in `I share` and the teacher extensions.

The learner may move from choosing correct forms to using passive voice when the affected object, device, or result is more important than the agent.

This is visible but not fully developed in the main learner-facing path.

### Grammar Learner -> Critical Reader

This transition is possible, but mostly teacher-mediated.

The critical reading article and newspaper activity suggest that passive voice can hide or shift responsibility. However, this is not deeply integrated into the main learner-facing sequence.

So the signal is strong conceptually, but weaker structurally inside the core brick.

### Isolated Form -> Functional Explanation

This transition appears in the device-writing activity.

Passive voice becomes a tool for explaining systems or processes. This is pedagogically coherent and practical:

```txt
The app was built...
The device is operated...
The object is heated...
```

The PDF does not develop this as the main path, but the teacher extension makes it credible.

### Correct Structure -> Socially Interpretable Message

The guessing game creates this possible transition.

The learner must produce or understand a description that others can interpret. Grammar correctness remains relevant, but the social success condition becomes:

```txt
Can others guess the intended object?
```

This resembles the Way-finding signal in a smaller way: successful language is language that works for someone else.

## 5. Emerging Responsibilities

This brick does not reveal one clean new responsibility.

It reveals a coordination problem:

```txt
one grammatical form
multiple pedagogical uses
```

The dominant learner-facing responsibility is:

```txt
grammar recognition and transformation
```

But several secondary responsibilities are visible:

- **focus awareness**: understanding what the passive voice foregrounds;
- **discourse awareness**: noticing how grammar can shape responsibility and narrative;
- **functional explanation**: using passive voice to explain devices or systems;
- **communicative play**: using passive descriptions for guessing and peer interpretation;
- **teacher orchestration**: expanding a grammar brick into critical, technical, or social activities.

The brick therefore seems hybrid.

It can be read as one dominant move if we only look at the learner-facing core:

```txt
learn the passive voice
```

But it resists simplification once the teacher extensions are included:

```txt
passive voice as form
passive voice as focus
passive voice as critical reading tool
passive voice as explanation tool
passive voice as social clue
```

## 6. Comparison With Previous POCs

### Thinking In English

`Thinking in English` is centered around learner posture:

```txt
self-awareness
-> speaking readiness
```

`Passive voice` is less about posture and more about the layered uses of a language form.

The similarity is that both resist being reduced to visible interaction shape. The difference is that `Thinking in English` has a clearer affective/metacognitive transition, while `Passive voice` contains several possible uses of the same grammatical structure.

### Memorising Vocabulary

`Memorising vocabulary` made the strategy itself the pedagogical object:

```txt
strategy is the content
```

`Passive voice` is different:

```txt
grammar is the content
but grammar opens several functions
```

This POC therefore reinforces a different signal: one content item can support several pedagogical directions.

### Way-finding

`Way-finding` surfaced action-oriented validation:

```txt
Can someone successfully navigate?
```

`Passive voice` has a weaker version of this in the guessing game:

```txt
Can others infer the object from my passive description?
```

It also has a functional explanation angle, but it is less situated than Way-finding. The action condition is more classroom/social than real-world navigational.

### Countable & Uncountable

`Countable & Uncountable` had a clearer guided conceptual progression:

```txt
examples
-> reasoning tool
-> grammatical distinction
```

`Passive voice` is more direct in its rule explanation. The conceptual layer exists, but it is not mainly discovered; it is explained and practised.

The richer signal comes later, when the grammar is extended into discourse and communication.

### Question Forms

`Question Forms` was a negative POC because it appeared closer to:

```txt
rule
-> exercise
-> more rule
```

`Passive voice` could look similar if only the main learner-facing sequence is considered.

But the `For teachers` section changes the reading. It suggests that a grammar brick may be conventional in its core path while still carrying high-potential extension routes.

This is important.

The brick does not become rich simply because it has many exercises. It becomes interesting because one grammatical feature can be used for multiple communicative and critical functions.

## 7. Temporary Conclusion

This POC does reveal something useful.

Most importantly:

```txt
the brick resists simplification
```

But it resists in a particular way.

The learner-facing path has a dominant intention:

```txt
teach passive voice grammar
```

However, the broader brick carries several pedagogical moves:

```txt
grammar recognition
-> focus awareness
-> discourse awareness
-> functional explanation
-> communicative play
```

These are not all equally developed. Some live mainly in teacher-facing suggestions. But they are not accidental: they all make sense because passive voice changes focus and can hide, shift, or foreground agency.

The main intuition to preserve is:

```txt
some bricks are pedagogically hybrid
because one linguistic form supports several learner functions
```

This is not yet a new architecture concept.

It is a caution for future POCs:

```txt
do not flatten a grammar brick too quickly
```

Sometimes the "extra" teacher section may contain the richest pedagogical signal.
