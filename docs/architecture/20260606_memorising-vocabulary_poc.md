# Memorising Vocabulary POC

## 1. Context

This POC belongs to the `experiment/bhe-be` branch.

The analyzed brick is:

```txt
REVAMP - Memorising vocabulary - Beci_VFv2.pdf
```

It was selected after the corpus cartography because it appeared to have high POC potential. In the cartography, it was described as a brick oriented toward:

```txt
metacognitive strategy activation
```

This document does not try to confirm a theory. It only tries to observe what the brick seems to do, and whether it surfaces a useful signal for future BHE-BE work.

## 2. What This Brick Seems To Do

At first glance, the brick is about memorising vocabulary.

But the learner-facing path does not mainly present a vocabulary list to learn. It organizes a sequence around how learners approach vocabulary learning:

```txt
reflect on current habits
-> discover one strategy
-> try the strategy
-> compare with other strategies
-> apply again in context
-> reflect on personal usefulness
-> discuss with others
```

The core recurring object is not a word list.

It is a learning method.

The brick starts with a quiz-like questionnaire, but the teacher note is explicit: there is no right answer. The purpose is to help the learner notice their current habits:

- Do I have a method?
- Which methods have I tried?
- Do I translate, connect, ignore?
- How often do I revise?

The later activities then make the learner test a concrete method: the word spider web. This is not only exposure to a strategy. The learner has to build one, connect meanings, use personal experience, imagine scenes, and decide which techniques might work for them.

## 3. What Is Actually Being Taught?

Several layers are present.

### Vocabulary

Vocabulary is present, but it is not the main object in the usual sense.

The brick uses words such as `play`, `critical`, `immersion`, `cue`, `substitute`, and `cluster`, but these are partly vehicles for trying a method.

The learner may learn some vocabulary, but the brick seems more interested in changing how future vocabulary will be learned.

### Learning Strategy

This appears to be the central teaching layer.

The learner is introduced to the idea that vocabulary can be retained through multiple strategies:

- association with existing knowledge;
- word webs;
- personal context;
- emotion or humour;
- visual or contextual cues;
- phrases and clusters;
- revision.

The brick does not only say "use strategies". It asks the learner to test them.

### Metacognition

The first and final reflective steps are strongly metacognitive.

The learner is asked to look at their own learning methods, then return to that reflection after trying techniques:

```txt
What works for me?
What did I try before?
Why did it not work?
What might I try next?
```

This is not a knowledge check.

It is self-observation.

### Learner Autonomy

The brick seems to support learner autonomy without making it abstract.

The learner is not simply given a method to obey. They are asked to compare methods, test them, and decide which ones may fit their own learning.

### Confidence

There is also a soft affective layer.

The feedback after the initial quiz says that learning and memorizing new words can feel overwhelming, then reassures the learner that they can take it step by step.

This is not the dominant layer, but it matters: the brick tries to reduce overwhelm enough for strategy experimentation to become possible.

## 4. Learner-State Changes

Possible learner-state changes are visible, but they should be described carefully.

### Implicit Habits -> Strategy Awareness

This is the strongest transition signal.

The initial quiz surfaces existing habits without judging them. The learner is moved from doing something implicitly to naming what they do.

This transition seems real.

### Random Memorization -> Intentional Memorization

This signal is also present.

The word spider web activity asks the learner to connect new vocabulary to existing knowledge, meanings, examples, images, personal scenes, and emotions.

The learner is encouraged to move from:

```txt
try to remember this word
```

to:

```txt
build conditions that make remembering more likely
```

This is a meaningful shift, but the brick only begins it. It does not yet establish long-term revision or spaced repetition.

### Passive Learner -> Reflective Learner

This transition is plausible, especially because the brick ends with a reflection and sharing step.

However, it should not be overstated. The learner can complete the brick without necessarily becoming deeply reflective. The brick creates an invitation and a structure for reflection; it does not guarantee the posture shift.

### Overwhelmed Learner -> Learner With Options

The reassurance after the first questionnaire and the later list of strategies suggest a weaker but interesting affective transition:

```txt
vocabulary is huge and vague
-> I have several possible techniques
```

This is not the same as confidence building in `Thinking in English`, but it is related.

## 5. Emerging Responsibilities

This brick does not necessarily reveal a completely new BHE concept.

It does, however, make one responsibility clearer:

```txt
learning strategy activation
```

This is more specific than generic reflection.

The learner is not only reflecting on feelings or habits. They are being prepared to modify how they learn.

Several responsibilities appear together:

- **metacognitive activation**: noticing current learning habits;
- **learning strategy awareness**: discovering and comparing possible techniques;
- **strategy rehearsal**: trying a method on a concrete word;
- **personalization**: connecting vocabulary to lived or imagined situations;
- **learner positioning**: deciding which strategies may fit oneself;
- **pedagogical preparation**: preparing future vocabulary learning beyond the brick.

The strongest signal may be:

```txt
strategy is the content
```

The brick is not simply about vocabulary as material to memorize. It is about making vocabulary learning itself available for reflection and deliberate action.

## 6. Comparison With Previous POCs

### Thinking In English

`Thinking in English` and `Memorising vocabulary` are close relatives.

Both begin with quiz-like reflection without real scoring. Both ask learners to examine habits. Both are less about checking knowledge than changing learner posture.

The difference is that `Thinking in English` moves toward oral activation:

```txt
self-awareness
-> speaking readiness
```

`Memorising vocabulary` moves toward strategy activation:

```txt
self-awareness
-> deliberate learning method
```

### Countable & Uncountable

`Countable & Uncountable` guides the learner toward a conceptual distinction:

```txt
examples
-> reasoning tool
-> grammar concept
```

`Memorising vocabulary` guides the learner toward a strategy:

```txt
habits
-> method
-> personal application
```

Both have guided progression, but the target is different. One stabilizes a grammar concept; the other helps the learner change their learning behavior.

### Question Forms

`Question Forms` was useful as a negative stress-test because the sequence seemed closer to:

```txt
rule
-> exercise
-> more rule
```

`Memorising vocabulary` feels different.

It is not only adding content or repeating exercises. The activities seem coordinated around a change in learner relation to learning vocabulary. That does not automatically justify a new model, but it does make the brick more than a conventional practice chain.

## 7. Temporary Conclusion

This POC mostly reinforces previous signals, but with a sharper angle.

It confirms again:

```txt
quiz-like shape
!=
assessment function
```

It also strengthens:

```txt
reflection
!=
knowledge check
```

The more specific emerging intuition is:

```txt
learning strategy activation
```

This may be a responsibility worth tracking in future BHE-BE observations.

However, it should not be stabilized yet as a core object or architecture layer. For now, it is safer to keep it as an analytical signal:

```txt
some bricks teach learners how to learn,
not only what to learn
```

The brique does reveal a learner-state change, but not a dramatic one. The most credible reading is:

```txt
implicit or fragile vocabulary habits
-> more explicit, intentional strategy awareness
```

That is a real pedagogical movement, and it is worth preserving in the BHE-BE memory.
