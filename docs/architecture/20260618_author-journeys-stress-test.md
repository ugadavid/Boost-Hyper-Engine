# Author Journeys Stress Test

## 1. Context

This document belongs to the experiment/bhe-be branch.

Recent BHE-BE work suggests:

- BHE can usually represent the observed activities;
- author discoverability remains uneven;
- authors appear to start from different places;
- no single authoring entry point explains the corpus.

A provisional hypothesis follows:

~~~txt
Perhaps authors do not need one workflow.

Perhaps several recurring design journeys coexist.
~~~

This document calls those reconstructed paths Author Journeys for convenience only.

The term does not name a new BHE concept, object, workflow, or implementation. It is an analytical label used to test whether recurrent paths clarify the corpus.

## 2. Methodological Limit

The Boost'English PDFs show completed design artifacts, not the actual chronology of author decisions.

A visible sequence such as:

~~~txt
content
-> explanation
-> practice
-> evaluation
~~~

may reflect:

- the real design process;
- a platform template applied afterward;
- editorial rearrangement;
- several revision passes;
- contributions from different people;
- a coherent story reconstructed after the fact.

The journeys below are therefore:

~~~txt
plausible design logics visible in the artifact
~~~

not:

~~~txt
verified histories of author thought
~~~

This distinction matters. A useful journey pattern can describe how a brick holds together without proving how its author created it.

## 3. Journey Reconstruction

### Thinking In English

A plausible journey is:

~~~txt
Learner difficulty:
translation and hesitation
->
Desired learner change:
greater self-awareness and speaking readiness
->
Reflective questionnaire:
notice current habits
->
Guided practice:
images, pronunciation, oral preparation
->
Speaking production
->
Reflection / sharing
~~~

The interaction shapes appear downstream from the learner problem.

The no-score questionnaire is not the destination. It opens a progression from awareness toward action.

A shorter journey summary is:

~~~txt
Learner Difficulty
-> Reflection
-> Selection
-> Non-scored Completion
-> Guided Oral Activation
-> Production
~~~

### Memorising Vocabulary

A plausible journey is:

~~~txt
Learner problem:
vocabulary learning feels difficult or unstructured
->
Self-observation:
surface current memorization habits
->
Strategy exposure:
show alternative ways to learn
->
Strategy trial:
word web, contextualization, recall
->
Comparison and self-adjustment
->
Reflection / sharing
~~~

The authoring logic appears strategy-led rather than vocabulary-list-led.

A shorter journey summary is:

~~~txt
Learning Habit
-> Reflective Survey
-> Strategy Awareness
-> Active Experimentation
-> Recall / Contextual Use
-> Self-adjustment
~~~

### Wayfinding

A plausible journey is:

~~~txt
Situated task:
ask for and give directions
->
Success condition:
another person can navigate
->
Required language:
directions, landmarks, polite questions, sequencing
->
Initial positioning:
check current control
->
Differentiated scaffolding
->
Controlled practice
->
Map-based production
->
Peer action validation
~~~

This looks closer to backward design from a real-world task.

The interaction shapes and language content are selected because the final action needs them.

A shorter journey summary is:

~~~txt
Situated Action
-> Success Criterion
-> Required Language
-> Scaffolding
-> Practice
-> Peer Validation
~~~

### Passive Voice - Learner-Facing Core

A plausible journey is:

~~~txt
Curricular content:
passive voice
->
Authentic or motivating exposure:
song examples
->
Rule and focus explanation
->
Recognition:
active or passive
->
Transformation:
active to passive
->
Corrective practice
->
Test / production
~~~

This is the clearest content-to-mastery journey.

A shorter summary is:

~~~txt
Curricular Content
-> Exposure
-> Explanation
-> Controlled Practice
-> Corrective Evaluation
-> Production
~~~

### Passive Voice - Teacher Extensions

The extensions suggest additional journeys layered onto the core.

Critical-reading journey:

~~~txt
Grammar Form
-> Notice Focus and Agency
-> Analyze Framing
-> Discuss Interpretation
-> Critical Reading
~~~

Functional explanation journey:

~~~txt
Grammar Form
-> Real Communicative Use
-> Explain How A Device Works
-> Produce Understandable Description
~~~

Guessing-game journey:

~~~txt
Known Form
-> Classroom Game
-> Produce Clues
-> Peer Inference
-> Communicative Success
~~~

Passive Voice therefore resists one journey. Its core and extensions may reflect different authoring starts and different design passes.

### Countable / Uncountable - I Learn

A plausible journey is:

~~~txt
Curricular distinction:
countable versus uncountable
->
Concrete examples
->
Guiding question:
can this be counted as 1 + 1 + 1?
->
Notice and compare
->
Infer distinction
->
Classify examples
->
Explicit conceptual stabilization
->
Practice
~~~

The content likely comes first, but the distinctive pedagogy lies in the guided cognitive route.

A shorter summary is:

~~~txt
Content Problem
-> Concrete Examples
-> Guided Comparison
-> Inference
-> Conceptualization
-> Practice
~~~

### Question Forms

A plausible journey is:

~~~txt
Curricular scope:
question forms and cases
->
Rule decomposition
->
Examples and tables
->
Exercise
->
Additional rule
->
More exercise
->
Corrective evaluation
~~~

This journey is less transformed by orchestration.

A shorter summary is:

~~~txt
Curricular Content
-> Rule Coverage
-> Repeated Practice
-> Corrective Evaluation
~~~

### Other Grammar Bricks

The corpus cartography suggests a recurrent broad path for conditionals, tense contrasts, adjective patterns, prefixes, comparatives, and superlatives:

~~~txt
Grammar or Lexical Topic
-> Example / Song / Dialogue
-> Rule or Contrast
-> Matching / QCM / Gap-fill
-> Pronunciation or Voicework
-> Test
-> Personal Production
~~~

The final production sometimes enriches the journey, but the visible organizing start remains content mastery.

## 4. Recurrent Journey Patterns

### Journey Family 1 - Content To Mastery

Typical form:

~~~txt
Curricular Content
-> Exposure or Explanation
-> Controlled Practice
-> Corrective Evaluation
-> Optional Production
~~~

Strong examples:

- Passive Voice core;
- Question Forms;
- tense contrasts;
- adjective and prefix bricks;
- conditionals.

This is the most frequent visible family across the corpus.

Its strength is clarity. Its risk is that interaction shapes become routine attachments to content rather than responses to a specific learner need.

### Journey Family 2 - Learner Problem To Awareness And Adjustment

Typical form:

~~~txt
Learner Habit or Difficulty
-> Self-observation
-> Reflective Response
-> Strategy or Guided Practice
-> Re-observation
-> Adjustment
~~~

Strong examples:

- Thinking in English;
- Memorising Vocabulary.

This family often uses quiz-like or selection interactions without assessment.

Its value comes from changing the learner's relation to learning or action, not only from adding content.

### Journey Family 3 - Situated Task Backward

Typical form:

~~~txt
Realistic Action
-> Success Criterion
-> Required Knowledge and Language
-> Scaffolding
-> Practice
-> Situated Validation
~~~

Strongest example:

- Wayfinding.

Smaller traces appear in:

- Passive Voice device explanation;
- Passive Voice guessing game;
- personal speaking extensions in grammar bricks.

This family makes success conditions especially visible.

### Journey Family 4 - Guided Discovery

Typical form:

~~~txt
Conceptual Problem
-> Concrete Examples
-> Notice / Compare
-> Infer
-> Explicit Stabilization
-> Practice
~~~

Strongest example:

- Countable / Uncountable.

Partial traces appear in:

- some prefix and adjective activities;
- tense contrasts grounded in dialogues or songs;
- grammar tasks that delay explanation until after observation.

This family is content-related but differs from direct explanation because the learner is guided toward the distinction before receiving its final formulation.

### Possible Journey Family 5 - Classroom Activity Extension

Typical form:

~~~txt
Known Content
-> Social or Playful Activity
-> Peer Meaning-making
-> Functional Reuse
~~~

Evidence appears mainly in For teachers sections:

- guessing games;
- map challenges;
- group discussion;
- peer questioning;
- story prompts.

This family may be real, but it is less stable. It may describe enrichment after the core journey rather than a full author journey of its own.

## 5. Minimal Set

A minimal set should explain most observed bricks without turning every variation into a named journey.

The smallest useful set appears to be four families:

1. Content To Mastery
2. Learner Problem To Awareness And Adjustment
3. Situated Task Backward
4. Guided Discovery

### Why four?

Content To Mastery covers most grammar and lexical bricks.

Learner Problem To Awareness covers the two strongest metacognitive bricks.

Situated Task Backward is necessary because Wayfinding cannot be described adequately as content mastery or reflection.

Guided Discovery is necessary because Countable / Uncountable differs meaningfully from direct rule transmission.

### Why not fewer?

Merging Guided Discovery into Content To Mastery would hide the difference between:

~~~txt
give rule
-> practise
~~~

and:

~~~txt
observe
-> compare
-> infer
-> stabilize
~~~

Merging Situated Task into Content To Mastery would hide the action-based success condition.

Merging Learner Problem into Guided Discovery would confuse metacognitive posture change with conceptual inference.

### Why not more?

Resource-first, template-first, classroom-activity-first, and constraint-first entry points are credible.

However, they currently behave more like modifiers or initiating circumstances than recurrent complete journeys.

For example:

- a song can serve Content To Mastery or Guided Discovery;
- a classroom game can extend Content To Mastery or Situated Task;
- the I start/I learn template can constrain any journey;
- a learner difficulty can initiate awareness or situated practice.

The minimal set is therefore descriptive, not exhaustive.

## 6. Contradictions And Resistant Cases

### Passive Voice Contains Several Journeys

Passive Voice begins as Content To Mastery, then opens into:

- critical analysis;
- functional explanation;
- communicative play.

One label for the whole brick is too coarse.

This suggests journeys may describe segments or layers, not necessarily whole bricks.

### Thinking In English Mixes Awareness And Production

The brick begins with Learner Problem To Awareness but ends with guided oral production.

It may be:

~~~txt
Awareness Journey
feeding
Situated or Productive Journey
~~~

The journey family boundary is not always the brick boundary.

### Memorising Vocabulary Makes Strategy Both Content And Intention

Learning strategies are:

- what is taught;
- what is tried;
- what is reflected on;
- what the learner may later adjust.

The brick can be read as learner-problem-first or content-first, because strategy itself becomes content.

This is a genuine ambiguity.

### Countable / Uncountable Could Be Retrospectively Narrated

The visible sequence supports Guided Discovery, but the PDF cannot prove that the author designed it from cognition outward.

It may have begun as a standard grammar topic and gained a good guiding question later.

### Question Forms May Be More Constrained Than Chosen

Its repeated rules and exercises may reflect:

- author preference;
- curriculum breadth;
- required template;
- platform limitations;
- inherited content.

A journey narrative can incorrectly attribute deliberate pedagogical coherence to structural constraints.

### For Teachers Sections May Be Separate Design Passes

Teacher extensions may not belong to the same journey as the learner-facing activity.

Treating them as one coherent path can erase the reality of iterative or collaborative authorship.

### Finished Artifacts Invite Storytelling

The largest contradiction is methodological.

Once a sequence exists, it is easy to write:

~~~txt
A
-> B
-> C
-> D
~~~

and make it look intentional.

Author Journeys can become elegant retrospective stories rather than evidence about author experience.

## 7. What Author Journeys Clarify

The journey lens helps with several things.

### It preserves different starting points

The author may begin with:

- content;
- learner difficulty;
- intended change;
- situated task;
- conceptual problem.

A journey can continue from each without forcing immediate translation into one abstract vocabulary.

### It connects entry point to later decisions

A starting point alone is not enough.

Author Journeys reveal how one decision may lead toward:

- cognitive operations;
- interaction shape;
- evidence;
- evaluation;
- feedback;
- continuation.

### It explains why the same interaction appears differently

Selection appears in both:

~~~txt
Learner Problem
-> Reflection
-> Selection
-> Completion
~~~

and:

~~~txt
Curricular Content
-> Knowledge Check
-> Selection
-> Corrective Evaluation
~~~

The shape is the same. The journey changes its pedagogical function.

### It may improve discoverability language

An author may recognize:

~~~txt
I am starting from a real task.
~~~

more easily than:

~~~txt
I need a particular abstract pedagogical type.
~~~

This is a useful observation, not a proposed interface.

## 8. What Author Journeys Obscure

### Real design is iterative

Authors may jump backward, reuse existing exercises, replace a resource, or add evaluation late.

A linear arrow sequence hides iteration.

### Journeys may overlap

One brick can start content-first, use guided discovery, and finish with situated application.

The families are not mutually exclusive.

### Journey granularity is unclear

Does a journey describe:

- a whole brick;
- one phase;
- one activity;
- one revision pass?

The corpus does not give one answer.

### The labels may become presets

If Content To Mastery or Guided Discovery becomes a recipe, the analytical lens may start prescribing pedagogy.

That would exceed the evidence.

### A journey does not replace pedagogical judgment

Two sequences can share the same arrows and differ radically in quality, support, accessibility, and meaning.

The pattern describes direction, not value.

## 9. Author Experience Implications

The corpus does not support one mandatory author workflow.

A single path such as:

~~~txt
Intention
-> Cognitive Operation
-> Interaction
-> Evaluation
~~~

would fit some cases and force others.

A single content-first path would reproduce the opposite problem.

The stronger observation is:

~~~txt
accept multiple entry paths
then converge on shared clarifying questions
~~~

Regardless of starting point, authors eventually need to consider:

- what learners should do mentally;
- what response is needed;
- why that response matters;
- whether correctness exists;
- what counts as meaningful evidence;
- what should happen next.

The recurring destination is more stable than the recurring start.

This is the main experience implication:

~~~txt
multiple beginnings
shared clarification
~~~

It does not imply multiple runtime pipelines. It only describes how authors may arrive at the existing BHE concepts.

## 10. Recommendation

Conclusion:

~~~txt
Author Journeys appear partially useful.
~~~

They are useful because they:

- preserve several credible starting points;
- explain why identical interactions serve different functions;
- connect author concerns to cognition, interaction, evaluation, and continuation;
- make the corpus easier to compare without requiring one workflow.

They remain partial because they:

- reconstruct rather than observe actual design chronology;
- simplify iterative work into linear arrows;
- overlap inside hybrid bricks;
- have uncertain granularity;
- risk becoming prescriptive templates.

The most frequent journey is:

~~~txt
Content To Mastery
~~~

The most distinctive alternatives are:

~~~txt
Learner Problem To Awareness And Adjustment
Situated Task Backward
Guided Discovery
~~~

The main counterexamples are:

- Passive Voice, which contains several journeys;
- Memorising Vocabulary, where strategy is both content and intention;
- Thinking in English, which moves from awareness into production;
- For teachers extensions, which may represent separate design passes.

The safest conclusion is:

~~~txt
Author Journeys are useful as navigation stories,
not as architecture and not as mandatory workflows.
~~~

## 11. Final Findings

### Document conclusion

Author Journeys reveal recurring design logics, but do not form a stable or exclusive model.

### Most frequent journeys

1. Content To Mastery
2. Learner Problem To Awareness And Adjustment
3. Situated Task Backward
4. Guided Discovery

### Main counterexamples

Hybrid bricks, teacher extensions, template-constrained sequences, and artifacts whose real design chronology is unknown.

### Main implication for BHE author experience

Do not require one starting path.

Allow authors to recognize their current starting situation, then help them reach common questions about cognition, response, evidence, evaluation, and continuation.
