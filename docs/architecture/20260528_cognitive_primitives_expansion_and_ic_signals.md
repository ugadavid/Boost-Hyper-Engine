## 4. Niveau B — opérations cognitives situées (IC)

Très important :

    ne pas confondre cognition générale
    et cognition située domaine-spécifique.

Les opérations IC sont ici considérées comme un terrain d’observation privilégié, non comme un modèle à imposer à BHE.

Exemples :

```txt
Transfer
Transcode
Recognize cognates
Filter ambiguity
```

Hypothèse prudente :

compositions spécialisées de primitives existantes.

Exemple :

```txt
Transcode
≈
Recognition
+
Transformation
+
Pattern transfer
```
