# Pedagogical Layers Stress Test

## 1. Context

This document belongs to the experiment/bhe-be branch.

The previous stress test showed that one provisional intention list mixed pedagogical goals, cognitive operations, interaction purposes, social organization, and affective dimensions.

A new hypothesis follows: perhaps there is not one list, but several descriptive layers:

- pedagogical intention;
- cognitive operation;
- interaction purpose;
- social mode;
- affective orientation.

This document does not validate those layers. It looks for separation, overlap, missing dimensions, and unnecessary complexity.

The central test is not whether every activity can be placed in a five-column table. Almost anything can be classified after the fact. The stronger question is:

> Does the separation reveal something that would otherwise remain confused?

## 2. Layer Separation Test

### Provisional meanings

| Candidate layer | Provisional question | Candidate examples |
| --------------- | -------------------- | ------------------ |
| Pedagogical intention | Why is the author creating this activity? What effect is sought? | Practice, recall, reflect, produce, apply, evaluate, diagnose |
| Cognitive operation | What does the learner do mentally? | Notice, compare, infer, analyze, classify, understand |
| Interaction purpose | What kind of response is being elicited, and why? | Survey, self-position, opinion gathering, preference collection |
| Social mode | With whom or in what participation arrangement does the activity happen? | Individual, pair, group, collaborative |
| Affective orientation | What affective condition or movement is supported? | Confidence, empathy, motivation, engagement, anxiety reduction |

This first definition already exposes instability.

Several proposed intentions are also learner operations: recall, reflect, and produce. Several interaction purposes describe data collection rather than pedagogy. Several affective orientations may be outcomes, enabling conditions, or teacher strategies.

The hypothesis is therefore not five clean taxonomies. At best, it is five questions asked from different viewpoints.

### Does the corpus contain distinct layers?

Yes, in several cases.

Thinking in English - I start can be read as:

- author purpose: prepare reflective awareness before speaking;
- learner cognition: notice, reflect, compare;
- interaction function: self-report and self-position;
- social arrangement: individual;
- affective orientation: reduce anxiety and normalize existing habits.

Those statements are not interchangeable. Separating them prevents a quiz-like interaction from being mistaken for assessment.

Wayfinding provides another positive case:

- author purpose: move language into situated use;
- learner cognition: identify, sequence, produce, transfer;
- interaction function: test whether directions can guide action;
- social arrangement: pair and collaborative verification;
- affective orientation: confidence through practical communicative success.

However, the separation is less useful for a conventional Question Forms exercise. Practice, identify/transform, individual work, and corrective checking may already describe it adequately. Forcing an affective orientation or special interaction purpose would add decorative analysis.

The separation is therefore conditionally useful:

- useful when several functions coexist;
- less useful when the activity is already simple and explicit.

## 3. Concrete Examples

The table keeps blank or cautious values where evidence is weak.

### What the table clarifies

The table protects several distinctions:

- a learner can reflect while an interaction serves self-positioning;
- an author can use a response diagnostically without the learner performing diagnosis;
- pair work is not automatically collaboration as a learning goal;
- confidence can be supported without becoming a cognitive operation;
- the same interaction may have a different function in a different sequence position.

### What the table obscures

The grid makes every layer look comparable and equally present. In reality:

- some layers describe the learner;
- some describe the author;
- some describe the environment;
- some describe how results are interpreted;
- some describe a hoped-for emotional effect;
- some only make sense relative to adjacent activities.

The table is analytically useful, but it should not be mistaken for a proven object shape.

## 4. Layer-by-Layer Stress Test

### Pedagogical Intention

This layer is useful because it asks why an activity exists. It distinguishes reflective questionnaires from scored QCMs, active recall from exposure, and situated application from isolated production.

Its candidate values remain unstable. Practice, recall, reflect, and produce often name learner actions. Evaluate and diagnose often name what a teacher or system does with evidence. Apply may name both learner action and intended transfer.

Pedagogical intention is useful as a question, but not yet stable as a list.

### Cognitive Operation

This is the most robust layer.

It has a clear subject, the learner, and a clear question: what does the learner do mentally?

The existing BHE vocabulary already supports associate, identify, classify, transform, infer, notice, compare, reflect, produce, imitate, self-adjust, and transfer.

The corpus repeatedly validates composability. The main tension is granularity. Understand names an inferred achievement more than an operation. Analyze may decompose into notice, identify, compare, infer, and reflect.

This layer is robust, but should not expand without discipline.

### Interaction Purpose

This layer exposes a real distinction: interaction shape is not what the interaction is used for.

A questionnaire can collect a correct answer, preference, opinion, self-report, diagnostic evidence, or reflective positioning.

Yet the candidate layer is internally heterogeneous:

- survey describes a collection pattern;
- self-position describes a possible learner effect;
- opinion and preference collection describe response semantics;
- diagnosis describes downstream interpretation.

The useful question may be narrower:

> What kind of response is this interaction eliciting, and how will it be used?

That does not stabilize a layer. It reveals why the current proposal is fragile.

### Social Mode

This layer is descriptively robust.

The corpus distinguishes individual, pair, small-group, whole-group, teacher-led, and collaborative work. Wayfinding needs another person for action-based verification. Passive Voice discussion and guessing depend on peers and teacher mediation.

But pair, group, and collaborative are not equivalent. Pair/group describe participant arrangement. Collaborative describes how participants work toward meaning or an outcome.

Social mode is also orthogonal to cognition. It may shape pedagogy strongly without belonging inside every pedagogical object.

### Affective Orientation

This is the most delicate layer.

The corpus contains real signals: anxiety reduction, confidence preparation, engagement through play, learner agency, and motivation through situated success.

But these differ in kind:

- anxiety reduction is a desired transition;
- confidence may be an outcome;
- engagement may be a condition or response;
- empathy is a cognitive-affective capacity;
- motivation may be an antecedent, process, or result.

Affective effects are difficult to infer safely from design. A playful task does not guarantee engagement. Pair work does not guarantee confidence. Critical reading does not guarantee empathy.

The layer captures something real, but currently invites overclaiming.

## 5. Ambiguities

### Self-position belongs where?

Self-position can be:

- an author intention;
- a reflective learner process;
- an interaction function;
- a result;
- a sequence-routing role.

The layer model does not solve this ambiguity. It reveals it.

### Diagnose belongs where?

Diagnosis may be:

- the author's reason for asking;
- the evaluator's interpretation policy;
- the sequence's routing function;
- a teacher-facing use of evidence.

Placing it under intention is plausible but incomplete.

### Apply versus transfer

Apply is useful in Wayfinding and functional Passive Voice tasks, but BHE already has transfer as a cognitive operation.

A possible distinction is applying within a task versus transferring across contexts. The corpus does not yet establish a reliable boundary.

### Reflect belongs in two layers

An author can intend to invite reflection while the learner performs reflection. The repeated word is not necessarily a flaw, but its role must remain explicit.

### Confidence is intention, orientation, or transition?

In Thinking in English, confidence can be a hoped-for outcome, an enabling condition, an affective orientation, or part of a learner-state transition. Forcing one placement loses information.

### Social mode versus interaction shape

A pair speaking task combines social mode, spoken exchange, production/listening/inference, application, and mutual understanding. These are distinguishable but tightly coupled. Excessive separation makes a simple activity laborious to describe.

### Scope remains unresolved

Passive Voice shifts from individual grammar practice to group critical discussion, technical writing, and communicative guessing. One profile for the whole brick flattens it; one profile per micro-activity may become verbose.

The layer hypothesis does not resolve whether it describes a brick, phase, or interaction.

## 6. Missing Layers

Several corpus dimensions do not fit comfortably into the five proposed layers.

### Learning Goal And Content Focus

What is being learned remains essential: passive voice, countability, learning strategies, directions, or speaking habits.

This is already partly covered by PedagogicalObject.learningGoal and should not be absorbed into intention.

### Evaluation Policy And Evidence Use

The corpus distinguishes scored correction, lightweight validation, reflective completion, diagnosis, peer verification, and successful action.

This dimension asks:

> What counts as evidence, and what is done with it?

BHE already separates evaluator, BHEResult, feedback, and routing, which structurally covers much of this.

### Success Criterion

Wayfinding and the guessing game show that success can mean a correct answer, navigable route, understandable explanation, interpretable clue, or meaningful completion without correctness.

### Sequence Or Orchestration Role

Some activities prepare, bridge, activate, consolidate, open reflection, or transition toward production. This role depends on what comes before and after.

The earlier Moment and PedagogicalTransition signals remain relevant here, but unstabilized.

### Scaffolding Or Guidance

Countable / Uncountable is defined partly by its guided path from examples to comparison, inference, and explicit stabilization. The same cognitive operations could receive very different levels of support.

### Teacher Mediation

The richest Passive Voice and Wayfinding extensions depend on teacher prompts, classroom organization, resources, follow-up questions, and interpretation of learner responses. This cannot be reduced to social mode.

### Situated Context

Wayfinding derives meaning from a map, destination, person needing directions, and practical action condition. Context changes what counts as a useful response.

### Learner-State Transition

The POCs repeatedly suggest unaware to self-aware, silent thought to speech, isolated vocabulary to situated communication, and rule receiver to rule discoverer.

This can clarify pedagogy, but remains descriptive and difficult to verify.

## 7. Architectural Usefulness

### What the separation improves

The layer approach is more useful than the original flat list because it prevents several collapses:

- QCM equals evaluation;
- pair work equals collaboration;
- reflection equals survey;
- production equals application;
- engagement equals cognition.

It also clarifies actors:

- the learner reflects;
- the author chooses a self-report interaction;
- the system records completion;
- the sequence may use the result diagnostically;
- the activity may support confidence.

This is a meaningful gain.

### What the separation risks

The five-layer model can quickly reconstruct the earlier Moment problem in pieces.

A complete description may require:

- intention;
- cognition;
- interaction purpose and shape;
- social mode;
- affective orientation;
- learning goal;
- evidence policy;
- success criterion;
- sequence role;
- scaffolding;
- teacher mediation;
- situated context.

At that point the model becomes an inventory of everything pedagogically relevant.

That may produce more descriptive completeness but less practical legibility.

The layer model is therefore strongest as a questioning discipline, not as proposed architecture.

### Relation to the existing BHE core

| Descriptive concern | Existing BHE coverage |
| ------------------- | --------------------- |
| Cognitive operation | Explicit CognitiveOperation vocabulary |
| Learning goal | PedagogicalObject.learningGoal |
| Interaction shape | InteractionMode, specialized InteractionData, renderer |
| Learner action | Semantic UserInput |
| Evidence and outcome | Evaluator and BHEResult |
| Feedback | FeedbackData and feedback rendering |
| Adaptation | AdaptiveRouting |
| Content and support | PedagogicalContent |

Less visible concerns include explicit author purpose, social arrangement, affective orientation, sequence role, and teacher mediation.

That does not prove that each requires a core concept. Some may remain documentation, authoring guidance, metadata, or concerns outside the runtime.

## 8. Recommendation

Conclusion:

> Layer separation appears partially useful.

It is more accurate than one flat vocabulary because it exposes category errors.

The most robust layer is Cognitive Operation. It has a clear actor, recurring evidence, composability, and an existing home in BHE.

A second useful descriptive axis is Social Mode. It is concrete and observable, although orthogonal to cognition and not necessarily a core concern.

The partially robust layers are Pedagogical Intention and Interaction Purpose. Both ask useful questions, but their values still mix actors, scopes, and functions. They work better as prompts than as stable vocabularies.

The most fragile layer is Affective Orientation. Affective dimensions are real, especially in Thinking in English, but the candidates combine conditions, goals, transitions, and hoped-for effects.

The main remaining ambiguities are:

- actor: learner, author, teacher, or system;
- scope: brick, phase, or interaction;
- process versus outcome;
- interaction purpose versus evidence use;
- social arrangement versus collaboration as a skill;
- affective support versus learner change;
- activity description versus sequence role.

The strongest conclusion is:

```txt
the separation is useful for asking better questions,
not yet for defining better objects
```

No layer should be stabilized or implemented from this stress test.
